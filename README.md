# Sudoku

Interaktywne sudoku w stylu sudoku.com: 6 poziomów trudności, notatki ołówkiem,
timer, błędy i wynik, sterowanie klawiaturą, motywy (także własny) i tryb skupienia.

**Zagraj:** https://igit418.github.io/sudoku/

## Skróty klawiszowe

| Klawisz | Działanie |
|---|---|
| Strzałki | ruch po planszy |
| 1–9 | wpisz cyfrę |
| Spacja | ołówek (notatki) ON/OFF |
| Shift + 1–9 | szybka notatka |
| Backspace / Delete | wymaż |
| Ctrl + Z | cofnij |
| H | podpowiedź |
| P | pauza |
| T | następny motyw |
| N | nowa gra |
| F | tryb skupienia |
| M | menu boczne |
| ? | lista skrótów |
